# でちゃう！取材・来店スケジュール（VRChatギミック用データ）

でちゃう！公式サイトの取材・来店スケジュールを30分おきに取得し、VRChatワールドのカレンダーギミックが読み込むデータを公開します。

- `docs/schedule.json` … 予定データ（ギミックが読み込む）
- `docs/thumbs.jpg` … サムネを1枚にまとめた画像（ギミックが読み込む）
- `docs/index.html` … ブラウザ版の表示
- `scripts/update.py` … 取得・生成スクリプト（GitHub Actionsで自動実行）

今すぐ更新したいときは、Actions タブ →「スケジュール更新」→「Run workflow」。
